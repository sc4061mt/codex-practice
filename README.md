# めぐる — ルーレット決定アプリ

iPhone の Safari を中心に使える、日本語のルーレット Web アプリです。HTML / CSS / JavaScript のみで動作し、外部 API・フォント・有料サービスは使いません。

## 起動方法

Python 3 がある環境で、このリポジトリ内から実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

PC のブラウザで `http://localhost:8000` を開きます。ビルドやパッケージのインストールは不要です。

## 使い方

1. 初回は食事のサンプル候補が 5 件表示されます。
2. 候補の入力欄をタップして編集し、入力を確定するか欄から移動すると保存されます。
3. 下の入力欄に候補を入力し、「＋ 追加」で追加します。「×」で削除できます。
4. 「スタート」で回転し、徐々に減速して約 5 秒で止まります。上の白い針が指す候補が、大きく結果表示されます。
5. 「もう一度まわす」で再抽選できます。毎回独立した抽選のため、同じ候補が連続することもあります。

候補は最大 50 件、名前は 40 文字までです。円内の長い名前は省略されますが、入力欄と結果には名前全体を表示します。候補が 0 件のときは抽選できません。回転中は編集できません。端末の「視差効果を減らす」設定では回転時間を短縮します。

候補は同じブラウザ・同じ URL の localStorage に自動保存します。すべて削除した状態も保存します。ブラウザのデータ削除、プライベートブラウズの終了、別端末・別 URL では候補は引き継がれません。保存できない場合は画面に通知し、その画面内では引き続き使えます。

## iPhone で確認する方法

PC と iPhone を同じ Wi-Fi に接続し、上記サーバーを起動した PC の LAN 内 IP アドレスを使って、Safari で `http://192.168.x.x:8000` を開いてください。必要に応じて PC のファイアウォールでポート 8000 のローカルネットワークからの接続を許可します。クラウド環境の localhost は iPhone から直接開けません。

または、このリポジトリの GitHub の Settings → Pages で、マージ後の `main` ブランチの `/ (root)` を公開元に設定すると、発行された HTTPS の URL を Safari で開けます（Pages を利用できるリポジトリ設定・プランが必要です）。公開設定はこの変更には含みません。Safari の共有メニューから「ホーム画面に追加」もできます。

## 動作確認

ブラウザで以下を確認できます。

- 初回の候補 5 件、候補の追加・編集・削除、再読み込み後の保持
- 回転中の操作制限、減速停止、針の位置と結果の一致、再抽選
- 全件削除時の抽選無効化、保存領域が使えない場合の通知
- iPhone サイズの縦画面とデスクトップで横にはみ出さないこと

実装は `index.html`、`styles.css`、`app.js` に分かれています。
